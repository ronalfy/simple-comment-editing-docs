# Finding the Plugin Settings

<figure><img src="../.gitbook/assets/Screenshot 2023-02-10 at 10.24.18.png" alt=""><figcaption><p>Comment Edit Lite Admin Screen</p></figcaption></figure>

## Finding the Admin Settings From the Plugins Screen

If you are on the plugin's screen, search for `Comment Edit Lite` and click on the `Settings` link.

<figure><img src="../.gitbook/assets/Screenshot 2023-02-10 at 10.26.16.png" alt=""><figcaption><p>Comment Edit Lite Plugin Row</p></figcaption></figure>

## Finding the Admin Settings from the Menu

Alternatively, in the admin menu, head to `Settings->Comment Edit Lite`.

<figure><img src="../.gitbook/assets/Screenshot 2023-02-10 at 10.27.25.png" alt=""><figcaption><p>Comment Edit Lite in the Settings Area</p></figcaption></figure>
